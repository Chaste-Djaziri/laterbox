# Security Policy

## Supported Versions

LaterBox actively maintains and releases security patches for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

We take the security of LaterBox, our users, and your personal data extremely seriously. If you discover a potential vulnerability or security issue, please notify us responsibly.

### Safe Protocol

1. **Do not create a public GitHub issue** for undisclosed security vulnerabilities.
2. Please disclose security issues by opening a private **[GitHub Security Advisory](https://github.com/Chaste-Djaziri/laterbox/security/advisories/new)** or emailing **[security@laterbox.dev](mailto:security@laterbox.dev)**.
3. Include detailed steps to reproduce the vulnerability, along with proof-of-concept payloads or screen recordings if applicable.

### Our Commitment

- **Acknowledgment**: We will acknowledge receipt of your vulnerability report within **24 hours**.
- **Assessment**: We will assess the severity and impact within **48 hours**.
- **Fix & Patch**: We will deploy a fix to the live web application and publish updated desktop/mobile/extension builds immediately.
- **Credit**: We will credit your discovery in our security changelog and release notes (unless you prefer anonymity).

Thank you for helping keep LaterBox and the open-source ecosystem safe!
