# Changelog

All notable user-facing changes to LaterBox will be documented in this file.

## [Unreleased]

### Changed
- **Fix Session Recognition in Sidebar and Settings**: Fixed an issue where the app displayed 'Guest Mode' and 'Sign In / Sync' in the sidebar and settings even while logged in with a valid session. Authenticated accounts are now instantly recognized on app launch and login, ensuring the user's avatar, email, and subscription details are properly rendered.
- **Immediate User Info, Display Name Detection & Catalog Sync on Login & App Open**: On sign-in, LaterBox immediately fetches fresh account metadata from Supabase to detect if a display name already exists, bypassing the display name prompt for returning users while prompting new users. It immediately initiates a full sync of items, collections, notes, and metadata on login, and refreshes the catalog whenever the app opens or resumes.
- **Simplified Onboarding & Auth Flow**: Replaced the multi-section welcome page with a clean, single-screen onboarding view. Unified sign-in and sign-up into a single email-first OTP flow — enter email, receive code, done. Removed password fields, separate signup page, and forgot password flow. Added slide-from-right push animation between onboarding and auth screens. Updated web login page to match the same passwordless flow.
- **CI: Fix macOS Build — SafariExtension & ShareExtension Code Signing**: Set `CODE_SIGN_STYLE = Manual` and cleared `CODE_SIGN_IDENTITY` for SafariExtension and ShareExtension Release/Profile build configurations in `macos/Runner.xcodeproj/project.pbxproj`. Prevents Xcode from attempting automatic provisioning profile lookup when `CODE_SIGNING_ALLOWED=NO` is passed by the CI xcodebuild invocation.
- **Redesigned Item Detail Page with Rich Content Banners**: Upgraded the mobile item detail page to match the web's rich multi-platform identification. Added content-type-specific banners for PSD/design files (vibrant gradient with Ps icon), PDF documents (simulated document sheet), Videos (hero cover with play badge), Music (album art with floating play button), Notes (paper squircle), and Articles (Notion branding). Added metadata top bar with favicon, domain, time ago, and status badge. Added inline collections pill bar, hashtag tag chips, styled amber captured highlight section, and platform-branded footer with contextual Open CTA (Open in Spotify, Watch on YouTube, Open in Notion).
- **Fixed Search Close Navigation**: Search close button now correctly returns to the source route (inbox or home) using GoRouter's extra parameter instead of relying on canPop/pop which failed inside ShellRoute.
- **Updated Guide & Tutorial Pages**: Overhauled the LaterBox Guide (`/guide`) and in-app Tutorial (`/tutorial`) to faithfully present LaterBox's calm return workflow (Universal Capture, Intentional Return Scheduling, Out-of-Sight Local Vault, and Timely Resurfacing). Updated the keyboard shortcuts cheat sheet to reflect the new `Control + Option + L` (`⌃⌥L`) capture shortcut and `Command + K` (`⌘K`) Spotlight search navigation, added comprehensive guidance on multi-platform rich formats (Design Files, PDFs, Videos, Music, Notes, Articles), and documented the Guest Mode demo card management controls.
- **Control + Option + L Shortcut to Open Quick Capture on Mac & Web**: Configured the global web keyboard shortcut on Mac (`Control + Option + L` / `⌃⌥L`, and `Ctrl + Alt + L` on PC) to summon the Quick Capture modal from anywhere in the application. Added a keyboard shortcut indicator badge (`⌃⌥L`) and tooltip to the 'Save Item' sidebar button, and updated keyboard shortcuts guides.
- **Rebound Cmd+K Shortcut to Search Instead of Create Item**: Reassigned the global `Command + K` / `Ctrl + K` shortcut to search interactions instead of opening the item creation modal. Pressing `Cmd + K` dynamically checks the active view: if an on-page search bar or filter input is present (such as in Inbox, Library, Today, Upcoming, Someday, or Deep Search), it focuses and selects the input; if no search bar is available on the current page (or when clicking the top dashboard omnibar), it opens an instant, Spotlight-style Search Modal with real-time vault queries, content format filters, quick navigation, and full keyboard navigation.
- **Accurate Cross-Tab Schedule Data Distribution Across Home, Inbox, Upcoming & Someday**: Ensured items on `/home`, `/inbox`, `/today`, `/upcoming`, and `/someday` faithfully reflect their actual scheduled states rather than concentrating all items into a single view. Distributed guest demo items across Returned Today, Upcoming (Tomorrow, Weekend), and the Someday Vault, and updated the home dashboard metric counters and timeline widgets to dynamically calculate counts from live scheduled data.
- **Removed Sidebar Collapse Icon**: Removed the sidebar collapse chevron toggle button from the application sidebar header (`AppSidebar.tsx`), keeping the sidebar stably expanded with clean brand presentation.
- **Multi-Platform Identification & Rich Previews on Item Details Page**: Upgraded the item details page (`/item/[id]`) with the same rich multi-platform identification and preview architecture found on item cards. Includes dedicated visual media banners for Photoshop/design files (vibrant gradient with Adobe `Ps` squircle and `• Design File` badge), PDF documents (simulated document sheet with red `PDF` badge and interactive viewer), Videos (hero cover thumbnail, `youtube.com` domain pill, and `▶ Video` badge), Music (Spotify album artwork with floating play button and `♪ Music` badge), Notes (paper squircle and `• Note` badge), and Articles (Notion branding with `Article` badge), complete with tag chips and platform actions.
- **Expanded Spacing Between Search Bar and Greeting Title**: Added generous vertical breathing room between the top search omnibar and the greeting header on the home dashboard (`/home`), establishing a cleaner visual hierarchy and preventing compressed layout above the greeting title.

### Added
- **Inbox device notifications**: Add opt-in scheduled-return and remote-save notifications across native apps and web, with local reminders and configurable cloud push delivery.
- **Personalized Display Name for Authenticated Users**: Added optional display name input after email OTP verification on both mobile and web. Users can enter a name during sign-up or skip it; LaterBox falls back to the email prefix. Display name persists via SharedPreferences (mobile) and localStorage (web), and is shown in the home greeting. Users can tap the greeting to update their name anytime.
- **AI Inbox Organize with Gemini**: Connected the 'AI organize Beta' card on `/inbox` directly to the Google Gemini API using the configured model and API key.
